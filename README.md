# Tech blog

Jednoduchý blog vytvorený v PHP a MySQL.

## Čo projekt obsahuje

- domovskú stránku s článkami
- detail článku
- admin login
- pridanie článku
- úpravu článku
- zmazanie článku

## Použité technológie

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Spustenie

1. Nahrať projekt do `htdocs`
2. Zapnúť Apache a MySQL v XAMPP
3. V phpMyAdmin vytvoriť databázu `php_blog`
4. Importovať súbor `database.sql`
5. Otvoriť projekt v prehliadači

## URL

Domov:
`http://localhost/blog/index.php`

Admin login:
`http://localhost/blog/admin/login.php`

## Admin údaje

Meno:
`admin`

Heslo:
`admin123`

## Poznámka

Projekt je urobený ako jednoduchá školská práca bez frameworku.
